# Юридико-техническая ревизия «Точки звука»

**Проекты для согласования. Ничего не опубликовано и не изменено в работающей форме или backend.**

Исходные данные — публичные документы https://tzvuka.ru/documents/, страницы филиалов и код действующего приёма заявок. Рядом сохранены HTML и текст опубликованных документов; контрольные суммы и сведения об исходных страницах филиалов — в source-manifest.json. Проверка выполнена 14 ноября 2026 года; это дата ревизии, не дата вступления проектов в силу.

1. [Политика](01-policy.md).
2. [Согласие на обработку заявки](02-consent-application.md).
3. [Отдельное согласие на рекламу](03-advertising-consent.md).
4. [Формулировки и согласия формы](04-form-copy.md).
5. [Дополнительное отдельное согласие на обработку данных для рекламы](02b-consent-marketing-data.md) — для консервативного разделения согласий по 152-ФЗ и 38-ФЗ; не относится к обязательной обработке заявки.
6. [Отчёт: изменения, риски, неподтверждённые сведения и источники](05-review-report.md).

В квадратных скобках обозначены сведения, которые необходимо получить у оператора. Они не заменены предположениями. Пока эти сведения не подтверждены, проекты не являются готовыми к публикации редакциями.

CRM описана в настоящем времени как функциональный способ обработки. Ни один проект не утверждает, что заявки сайта уже поступают конкретному поставщику CRM.

Открытые вопросы по Telegram/трансграничной передаче, договорам с обработчиками, срокам и удалению данных нельзя закрыть одним изменением текста. Они перечислены в отчёте для решения оператором и профильным юристом.
