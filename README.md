# Точка звука — сайт

Статический сайт без внешних зависимостей. Основной домен: tzvuka.ru.

- / — выбор города;
- /troitsk/ и /kaluga/ — самостоятельные страницы филиалов;
- /privacy/ и /consent/ — общие документы;
- прежние privacy.html, consent.html и ссылки /#kaluga, /#troitsk ведут к новым страницам.

## Правки и локальный просмотр

Общий дизайн страниц городов: templates/city.html. Данные филиалов и главная: scripts/build_site.py. Городские HTML в site/ пересоздаются при сборке. Документы редактируются непосредственно в site/privacy/index.html и site/consent/index.html, оформление — site/legal.css.

```powershell
python scripts/build_site.py
python scripts/check_site.py
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:8765/. Сборка использует стандартную библиотеку Python 3; проверка синтаксиса JavaScript требует Node.js.

## Запись на занятия

Кнопки записи открывают контакты: +7 995 790-76-70 и tzvuka@yandex.ru. Тема письма включает филиал и выбранное направление. Сайт не собирает персональные данные через форму и не имитирует отправку заявки. Аналитика, рекламные пиксели и localStorage не используются.

Для приёма заявок через сайт нужны реальный сервис обработки с подтверждением доставки, отдельный механизм согласия и актуализация документов под фактическую обработку. Endpoint и серверные учётные данные не подключены.

## Публикация

.github/workflows/pages.yml собирает и проверяет сайт, затем публикует site/ на GitHub Pages при пуше в main. site/CNAME содержит tzvuka.ru.

В GitHub Pages должны быть выбраны GitHub Actions, настроен домен tzvuka.ru и HTTPS; DNS домена должен указывать на GitHub Pages. Файл CNAME сам по себе не подтверждает настройки DNS, домена и сертификата. После пуша проверяйте успешный workflow и доступность домена.

Редакция документов датирована 10.11.2026 и действует с момента публикации. Не добавляйте неподтверждённые сведения о сроках хранения, сервисах, инфраструктуре или регистрации товарного знака.
