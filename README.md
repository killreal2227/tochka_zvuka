# Точка звука — сайт

Статический сайт без внешних зависимостей. Проверенный публичный HTTPS-адрес: https://killreal2227.github.io/tochka_zvuka/. Домен tzvuka.ru пока требует исправления DNS/HTTPS.

- / — выбор города;
- /troitsk/ и /kaluga/ — самостоятельные страницы филиалов;
- /privacy/ и /consent/ — общие документы;
- прежние privacy.html, consent.html и ссылки /#kaluga, /#troitsk ведут к новым страницам.

## Правки и локальный просмотр

Точечные правила главной: `site/home.css` (подключён только на главной после общих стилей). Анимация её паттерна: `site/home-motion.js`. Порог узкой версии — viewport до 1000 px включительно. Публичный базовый URL для canonical, Open Graph, sitemap и robots задаётся в `site-config.json`; после исправления домена сменить его и пересобрать сайт.

Проверка регрессий без браузера: `node --test --test-isolation=none scripts/home-regression.test.mjs backend/leads.test.mjs`. Это тесты каскада объявлений CSS, модели анимации и серверного обработчика с имитацией Telegram, а не проверка геометрии настоящего браузера. Аудит и оставшиеся вопросы: [docs/home-audit-20261110.md](docs/home-audit-20261110.md).

Страницы: templates/home.html и templates/city.html. Общие подвал и форма: templates/footer.html и templates/lead-dialog.html. Главная, компактный подвал и лёгкое движение знака: site/experience.css. Прежнее оформление формы с паттерном, круглыми иконками и сменой акцентного цвета: site/form.css; поведение и отправка — site/lead-form.js. Паттерн внутри знака: site/patterns/brand.svg. Данные филиалов: scripts/build_site.py. HTML в site/ пересоздаются при сборке. Документы редактируются непосредственно в site/privacy/index.html и site/consent/index.html, оформление — site/legal.css.

```powershell
python scripts/build_site.py
python scripts/check_site.py
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:8765/. Сборка использует стандартную библиотеку Python 3; проверка синтаксиса JavaScript требует Node.js.

## Запись на занятия

Актуальное уточнение: отдельный флажок заменён текстом со ссылками непосредственно у кнопки отправки. При `endpoint:null` показывается согласованная владельцем отбивка «Спасибо, заявка отправлена», поля очищаются, данные не сохраняются и не передаются. Это не реальный приём заявок. Место подключения — `window.TZ_LEADS.endpoint` в `site/lead-form.js`; порядок включения и версия обработчика описаны в `backend/README.md`.

На филиалах `site/direction-player.js` обеспечивает одну анимацию направления; `site/city-ui.js` и `site/city-ui.css` отвечают за компактное предложение записи раз за сессию и выравнивание кнопок вне шапки. Основные сценарии проверяются командой `node --test --test-isolation=none scripts/home-regression.test.mjs scripts/city-interactions.test.mjs backend/leads.test.mjs`.

Кнопки записи открывают общую форму: имя, телефон, филиал и необязательное направление. На страницах городов филиал подставляется со страницы. Согласие описано текстом у отправки со ссылками на документы. Данные не сохраняются в localStorage. Для посетителей также доступны +7 995 790-76-70 и tzvuka@yandex.ru.

Серверный обработчик отправки в Telegram подготовлен в backend/; порядок подключения — backend/README.md. Пока endpoint в site/lead-form.js равен null, отбивка завершает интерфейс без реального приёма. Токен бота не размещается в клиентском коде. Перед включением endpoint нужно проверить реальный приём заявки. Аналитика и рекламные пиксели не подключены. Полный актуальный отчёт: [docs/site-audit-20261110.md](docs/site-audit-20261110.md).

## Публикация

.github/workflows/pages.yml собирает и проверяет сайт, затем публикует site/ на GitHub Pages при пуше в main. site/CNAME содержит tzvuka.ru.

В GitHub Pages должны быть выбраны GitHub Actions, настроен домен tzvuka.ru и HTTPS; DNS домена должен указывать на GitHub Pages. Файл CNAME сам по себе не подтверждает настройки DNS, домена и сертификата. После пуша проверяйте успешный workflow и доступность домена.
