# Одноколоночная запись филиалов

- Только Калуга и Троицк используют новый шаблон `branch-lead-dialog.html` и изолированный `branch-form.css`. Главная сохраняет исходный шаблон формы.
- Декоративная колонка удалена. Сверху вниз: подпись, Architexture-заголовок, пояснение, телефон, имя, выбор направления, широкая кнопка, неизменённое согласие, вторичный звонок. Обычный текст — уже используемый Arial, без новой гарнитуры.
- Окно шириной до 620 px, скругление 14 px, ограниченная высота и вертикальная прокрутка. Шесть направлений — три столбца и два ряда; «Пока не знаю» ниже на всю строку. Все подписи видимы и переносятся, без горизонтального ряда с прокруткой. Исходные SVG и круги 52 px сохранены.
- В обработчике предусмотрен вариант без SVG-панели. Выбор направления, ветка филиала, проверки полей, закрытие и текущий сценарий локального подтверждения сохранены; endpoint не подключался. Данные оператора, юридический текст и ссылки не менялись. Тестовые заявки наружу не отправлялись.
- Проверки: сборка и статические ссылки/синтаксис, 34 Node-теста, включая открытие и локальный результат формы без SVG для обоих городов. Исходная разметка формы главной и юридический блок сравнены с предыдущим коммитом. Браузерная визуальная проверка не выполнена: доступ недоступен.
