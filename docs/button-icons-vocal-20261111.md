# Кнопки, контуры и фон вокала — 11 ноября 2026

UPDATE: Icon stroke normalization was reverted at the owner's request. Original SVG strokes and scaling are restored; capsule centering and the vocal background pulse remain.

- Новый общий `button-labels.js` сохраняет исходную надпись в потоке для неизменных размеров и положения стрелки. Видимая копия текста центрируется по SVG getBBox: горизонтально в области от левого края до стрелки, вертикально по границам букв. Учитываются загрузка шрифта, изменение ширины и показ скрытой формы. Копия скрыта от accessibility tree, исходная надпись доступна. Без JS исходный текст остаётся видимым.
- Обводки исходных SVG формы и inline-значков карточек приведены к 1,65 CSS px с non-scaling-stroke. Эталон — стрелка шапки филиала: stroke-width 2,2 при размере 15/20. В брендбуке отдельное численное веб-правило не обнаружено; 1,65 px — адаптация указанного владельцем эталона. Формы, цвета, заливки, ширина рисунков и центры окружностей не изменены. Чёрные элементы, заданные заливкой, сохранены; они не превращались в новые линии.
- Только у вокала подготовка анимации выбирает видимые горизонтальные штрихи фона. По ним последовательно проходит короткий импульс смещения/растяжения с возвращением в исходное положение; старое прорисовывание и вибрация не запускаются. Не добавлены новые SVG-элементы, оригинальный файл фона не изменён. Микрофон не увеличивается; текстовые эффекты не добавлены. Уход курсора немедленно снимает play существующим проигрывателем; повторный hover запускает цикл сначала. Reduced-motion отключает запуск.
- Проверены: сборка, локальные ссылки и синтаксис, 33 Node-теста (включая модель центрирования по границам букв, пересчёта и отбора только горизонтальных полос вокала), равенство геометрии/заливок SVG с предыдущей версией. Разметка обеих шапок сравнена — не менялась.
- Браузерная визуальная проверка, фактические размеры DOM на узком/широком экране и субъективная плавность не проверены: браузерный доступ недоступен. Модельные тесты не заменяют такую проверку.
