# Кнопки, контуры и фон вокала — 11 ноября 2026

Последнее уточнение: вокальные полосы используют ту же прорисовку ap/rev, что остальные направления: при старте play скрыты через stroke-dashoffset и backwards fill, затем появляются последовательно, после чего запускается импульс. Общая длительность 2,6 с; матрицы path сохранены. В обычном состоянии и после ухода фон исходный. Главная при ширине от 1001 px: логотип фиксированно 260 px, кнопка 230×54 px, шапка 88 px с вертикальным центрированием; узкая версия не менялась. Модельные регрессионные проверки обновлены, все 33 теста пройдены. Браузерная проверка недоступна.

Исправление импульса: у исходного вокального SVG все полосы находятся в общей группе opacity и имеют собственные transform=matrix. Применение CSS transform прямо к path заменяло эту матрицу. Теперь каждая полоса получает нейтральную группу для анимации, исходный path и его transform сохраняются. Амплитуда поднята с 7 до 28 единиц большого viewBox (несколько экранных пикселей). Регрессионная модель воспроизводит общую группу из 12 полос и проверяет анимацию обёртки без изменения матрицы path. Визуальная проверка в браузере не выполнена.
