Форма содержит имя, телефон, выбранный филиал и интересующее направление. Направление можно не выбирать. Эти сведения предназначены для консультации и согласования первого занятия.

Цель обработки обращений — ответить на запрос, проконсультировать и согласовать занятие. Для этого оператор может получать, записывать, хранить, уточнять и использовать сведения для связи, а затем удалять их, когда они больше не нужны для цели обращения, если нет другого основания для хранения. Рекламные рассылки не входят в эту цель.

К обращениям должны иметь доступ только лица, которым они необходимы для ответа и организации занятия. Конкретные сроки хранения обращений и порядок доступа можно уточнить у оператора по указанным выше контактам.
