# Развёртывание MVP

Актуальные инструкции: [BULK-MVP.md](BULK-MVP.md) и [WEBSITE-PUBLICATION.md](WEBSITE-PUBLICATION.md).
Облачные результаты: [LAUNCH-RESULT.local.md](LAUNCH-RESULT.local.md).

Использовать только основную index.handler версию по согласованному именованному тегу.
Диагностические версии и $latest не предназначены для Gateway сайта.
api-gateway.bulk-mvp.json содержит фактический Gateway; старый api-gateway.openapi.json — исторический черновик с несогласованным SWS placeholder.
Публикация сайта и включение публичного приёма требуют отдельного подтверждения.
